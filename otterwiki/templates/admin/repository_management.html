Git 服务与远程同步

{##}
启用后，具有读取权限的用户可以通过 Git 克隆和拉取 Wiki 内容，具有上传／附件管理权限的用户可以推送。启用后 {{url_for("dotgit", _external=True)}} 会显示在用户的设置页中。
{##}
启用后，每次 Wiki 内容变更都会自动通过 SSH 推送到远程 Git 仓库。
{# push configuration parameters #}
用于推送的 SSH 远程地址，支持以下格式：
  • ssh://[user@]host.xz[:port]/path/to/repo.git
  • git://host.xz[:port]/path/to/repo.git
  • git@github.com:username/repo.git（GitHub 等）
用于认证的可选 SSH 私钥。服务器无需认证或由外部处理时请留空。 私钥保存后不会再显示。 为确保安全，强烈建议创建一个仅用于访问此远程仓库的专用密钥。
{##}
启用后，可通过触发 Webhook URL 自动从远程 Git 仓库拉取变更。
{# pull configuration parameters #}
用于拉取的 SSH 远程地址，支持以下格式：
  • ssh://[user@]host.xz[:port]/path/to/repo.git
  • git://host.xz[:port]/path/to/repo.git
  • git@github.com:username/repo.git（GitHub 等）
用于认证的可选 SSH 私钥。服务器无需认证或由外部处理时请留空。 私钥保存后不会再显示。 为确保安全，强烈建议创建一个仅用于访问此远程仓库的专用密钥。
{% if not config.GIT_REMOTE_PULL_URL_SECURE and config.GIT_REMOTE_PULL_URL %}
当前 Webhook URL 使用的旧版哈希可由远程仓库地址推导得出。 请勾选下方复选框并保存偏好设置，以生成更安全的 Webhook URL。 注意：Webhook URL 将发生变化，已有 Webhook 配置也需要更新。
{% endif %}
使用此 URL 触发外部服务（如 GitHub Webhook）的自动拉取。
远程 URL 已更改，请保存设置以生成新的 Webhook URL。
