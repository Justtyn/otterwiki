# 关于 An Otter Wiki

[An Otter Wiki](https://otterwiki.com) 是一款用于协作式内容管理的软件，也称为 [维基](https://en.wikipedia.org/wiki/Wiki)。内容存储在 git 仓库中，由其跟踪所有数据和更改。使用 [Markdown](https://daringfireball.net/projects/markdown) 作为标记语言。

本项目托管在 [github](https://github.com/redimp/otterwiki) 上。
它使用 [python](https://www.python.org/) 与微框架 [Flask](http://flask.pocoo.org/) 编写，采用 [halfmoon](https://www.gethalfmoon.com) 作为 CSS 框架、[CodeMirror 6](https://codemirror.net/) 作为编辑器，图标由 [Font Awesome Free](https://fontawesome.com/license/free) 提供。Roboto 字体版权所有 2011 Google Inc.，保留所有权利。
